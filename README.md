# algorithms-mipt

Решения задач курса алгоритмов на ФПМИ МФТИ. Задачи из Яндекс.Контеста, все решения приняты системой.

Каждая задача лежит в отдельной папке: `README.md` с условием и разбором решения и `solution.cpp` с самим кодом.

| Тема | Задач | Что внутри |
|------|-------|------------|
| [Динамическое программирование](dp/) | 19 | Рюкзаки, подпоследовательности, динамика по подмножествам и по профилю, матричное возведение в степень |
| [Графы](graphs/) | 20 | Обходы, топсорт, компоненты связности, мосты, кратчайшие пути, остовные деревья, СНМ |
| [Деревья](trees/) | 10 | Деревья отрезков, дерево Фенвика, декартово и splay-дерево |
| [Потоки и паросочетания](flows-and-matchings/) | 7 | Алгоритм Куна, сведения к паросочетаниям, максимальный поток, минимальный разрез |
| [Простые задачи](simple-algos/) | 2 | Очередь с максимумом, скользящее окно |

## Что посмотреть в первую очередь

Задачи, где решение не сводится к применению известного алгоритма по шаблону.

**Динамическое программирование**

- [Красивая табличка](dp/18-krasivaya-tablichka/) - число строк доходит до $10^{100}$, поэтому матрица переходов возводится в степень, записанную в самописной длинной арифметике.
- [Клики](dp/19-cliques/) - встреча посередине на $2^{50}$ подмножествах: половины считаются отдельно, а склеиваются суммированием по подмаскам.
- [Хрустальный шар](dp/02-hrustalnyj-shar/) - переход вида «минимум максимума» ищется бинарным поиском по монотонности, что убирает из перебора целый множитель.

**Графы**

- [Лифты и телепорты](graphs/17-lifty-i-teleporty/) - миллион этажей сжимается до сотни тысяч интересных, а телепорт становится отдельной вершиной, чтобы клика рёбер превратилась в звезду.
- [Сжечь мосты](graphs/07-szhech-mosty/) - ответ считается по листьям дерева мостов, но сама конденсация не строится: признак листа возвращается из того же обхода.
- [Поиск лекторов](graphs/20-poisk-lektorov/) - приглашение лектора моделируется ребром от фиктивной вершины, после чего задача становится обычным минимальным остовным деревом.

**Деревья**

- [Количество чисел из диапазона на отрезке](trees/11-range-count-queries/) - дерево отрезков, в узлах которого лежат не значения, а деревья поиска.
- [Отрезки на прямой](trees/10-otrezki-na-pryamoj/) - треап по координате начала отрезка, в узле - сумма квадратов длин поддерева, поэтому ответ на запрос берётся из корня за $O(1)$.
- [Очередная странная структура](trees/03-ocherednaya-strannaya-struktura/) - офлайн-сжатие координат и неявное дерево отрезков, где узлы создаются только по мере обращения.

**Потоки и паросочетания**

- [Доминошки и квадраты](flows-and-matchings/02-dominoshki-i-kvadraty/) - шахматная раскраска превращает укладку доминошек в паросочетание, а выбор между доминошкой и парой квадратов остаётся чистой арифметикой.
- [Минимальное вершинное покрытие](flows-and-matchings/03-minimum-vertex-cover/) - теорема Кёнига: покрытие строится из готового паросочетания одним обходом.
- [Поток минимальной стоимости](flows-and-matchings/07-mincost-maxflow/) - отрицательные стоимости на обратных рёбрах не дают применить Дейкстру, поэтому кратчайшие пути ищет Беллман-Форд.

**Простые задачи**

- [Корабль в пространстве](simple-algos/01-korabl-v-prostranstve/) - максимум на трёхмерном окне тремя проходами очереди с максимумом, а ответы восстанавливаются сжатием путей в функциональном графе.

## Сборка

Код на C++20, без внешних зависимостей, каждое решение - один файл:

```bash
g++ -std=c++20 -O2 -Wall -Wextra solution.cpp -o solution
```
