# B. Много колодцев

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

На прямой даны $n$ точек $x_1, x_2, \ldots, x_n$. В каждой из них расположен дом. Вы можете вырыть $m$ колодцев, но только в точках с теми же координатами, что и дома, - то есть колодцы могут быть расположены только в точках $x_1, x_2, \ldots, x_n$.

Затем жители каждого дома выбирают ближайший к ним колодец. Ваша цель - вырыть колодцы так, чтобы минимизировать суммарное расстояние, проходимое жителями от домов до колодцев.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 300$, $1 \le m \le \min\{30, n\}$).

Вторая строка содержит $n$ целых чисел $x_1, x_2, \ldots, x_n$ ($1 \le x_i \le 10^4$). Гарантируется, что $x_1 < x_2 < \ldots < x_n$.

## Формат вывода

В первой строке выведите минимально возможное суммарное расстояние между домами и ближайшими к ним колодцами.

Во второй строке выведите $m$ координат колодцев в возрастающем порядке.

Если решений несколько, выведите любое.

## Решение

Динамика по числу вырытых колодцев: $dp[k][i]$ - минимальная суммарная стоимость, если вырыто $k + 1$ колодцев и самый правый из них стоит в точке $i$. База $dp[0][i]$ - все дома ходят к единственному колодцу $i$, эта величина выражается через префиксные суммы за $O(1)$.

Переход добавляет колодец $i$ правее предыдущего колодца $j$: часть домов между ними переключается с $j$ на $i$. Изменение стоимости $\Delta_{ij}$ не зависит от $k$, поэтому все такие величины считаются один раз заранее. Граница переключения - середина отрезка между $x_j$ и $x_i$, она находится бинарным поиском, а суммы координат по обе стороны от неё - теми же префиксными суммами.

Ответ - минимум по последнему колодцу; сами координаты восстанавливаются по массиву предков.

Итого $O(n^2)$ на предподсчёт $\Delta$ и $O(mn^2)$ на динамику.
