# C. Хрустальный шар

`1 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

У вас есть несколько одинаковых хрустальных шаров, и вы хотите испытать их на прочность, сбрасывая с разных уровней Пизанской башни.

В башне всего $n$ уровней, пронумерованных числами от $1$ до $n$. Шар разобьётся, если сбросить его с $y$-го уровня при $y \ge x$, и не разобьётся при $y < x$ для некоторого неизвестного целого $x \in [1, n]$. Если шар разбился, больше им пользоваться нельзя.

У вас есть всего $k$ хрустальных шаров. Определите наименьшее количество бросков, которое необходимо совершить, чтобы гарантированно определить значение $x$.

## Формат ввода

Единственная строка содержит два целых числа $n$ и $k$ ($1 \le n \le 10^5$, $0 \le k < n$).

## Формат вывода

Выведите наименьшее необходимое число бросков. Если решения не существует, выведите $-1$.

## Решение

$dp[b][j]$ - минимальное число бросков, гарантированно определяющее ответ среди $j$ уровней при $b$ шарах. Бросок с уровня $m$ делит задачу на два случая: шар разбился - остаётся $b - 1$ шар и $m$ уровней снизу, шар цел - остаётся $b$ шаров и $j - m$ уровней сверху. Худший случай - максимум из двух, поэтому $dp[b][j] = \min_m \max(dp[b-1][m],\ dp[b][j-m]) + 1$.

Перебирать все $m$ слишком дорого, но по $m$ первая величина не убывает, а вторая не возрастает, поэтому минимум максимума достигается на их пересечении и ищется бинарным поиском по разности - это убирает множитель $n$ из перебора.

Ответ ограничен сверху числом бросков при делении пополам: больше $\lceil \log_2 n \rceil$ бросков не нужно никогда, поэтому число шаров срезается до этого значения, и таблица остаётся размера $O(n \log n)$. Случаи $k = 0$ разбираются отдельно: без шаров ответ есть, только если уровень всего один.

Итого $O(n \log^2 n)$.
