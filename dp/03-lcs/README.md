# D. LCS

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Даны две строки. Найдите их наибольшую общую подпоследовательность.

## Формат ввода

Первая строка содержит строку $s$ ($1 \le |s| \le 10^3$).

Вторая строка содержит строку $t$ ($1 \le |t| \le 10^3$).

Обе строки состоят из маленьких латинских букв.

## Формат вывода

В первой строке выведите $k$ - длину наибольшей общей подпоследовательности строк $s$ и $t$.

Во второй строке выведите $k$ индексов строки $s$, задающих эту подпоследовательность.

В третьей строке выведите $k$ индексов строки $t$, задающих эту подпоследовательность.

Если существует несколько решений, выведите любое.

## Решение

Стандартная динамика $dp[i][j]$ - длина наибольшей общей подпоследовательности префиксов $s[1..i]$ и $t[1..j]$: при совпадении символов берётся $dp[i-1][j-1] + 1$, иначе максимум из двух соседних состояний.

Ответ нужно ещё и предъявить, поэтому вместе с длиной хранится ссылка на последнюю совпавшую пару позиций. Когда переход добавляет символ, ссылка указывает на текущую клетку, иначе копируется из той клетки, откуда пришло значение. Восстановление идёт по этим ссылкам от $dp[|s|][|t|]$ назад: каждая ссылка даёт пару индексов ответа, после чего разбор продолжается из клетки левее и выше.

Итого $O(|s| \cdot |t|)$ времени и памяти.
