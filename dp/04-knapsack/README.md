# E. Рюкзак

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Даны $n$ предметов. Каждый из них имеет свои вес $w_i$ и стоимость $c_i$.

Также есть рюкзак прочности $m$. Вы можете сложить некоторые из предметов в рюкзак, но только при условии, что суммарный вес выбранных предметов не превосходит $m$. Какие предметы нужно выбрать, чтобы они уместились в рюкзак, а их суммарная стоимость была максимальной?

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 100$, $1 \le m \le 10^4$).

Вторая строка содержит $n$ целых чисел $w_1, w_2, \ldots, w_n$ ($1 \le w_i \le 100$) - веса предметов.

Третья строка содержит $n$ целых чисел $c_1, c_2, \ldots, c_n$ ($1 \le c_i \le 100$) - стоимости предметов.

## Формат вывода

Выведите список номеров предметов, которые нужно выбрать. Если решений несколько, выведите любое.

## Решение

Рюкзак 0-1: $dp[i][w]$ - максимальная стоимость, набираемая первыми $i$ предметами при вместимости $w$. Переход - взять предмет или пропустить его.

Нужен сам набор, поэтому вместе со значением хранится состояние, из которого оно получено. Восстановление идёт от $dp[n][m]$ назад: если предыдущее состояние отличается вместимостью, значит на этом шаге предмет был взят, и его номер попадает в ответ.

Итого $O(nm)$ времени и памяти.
