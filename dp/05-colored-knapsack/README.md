# F. Цветной рюкзак

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Даны $n$ предметов. Каждый из них имеет свои вес $w_i$, стоимость $c_i$, а также цвет $f_i$.

Назовём набор предметов пёстрым, если все предметы в нём имеют попарно различные цвета.

Также есть рюкзак прочности $m$. Вы можете сложить некоторые из предметов в рюкзак при условии, что суммарный вес не превосходит $m$ и набор является пёстрым. Какую максимальную стоимость может иметь такой набор?

## Формат ввода

Первая строка содержит три целых числа $n$, $g$ и $m$ ($1 \le g \le n \le 300$, $1 \le m \le 10^4$) - число предметов, количество различных цветов и вместимость рюкзака.

В $i$-й из следующих $n$ строк содержится три целых числа $w_i$, $c_i$ и $f_i$ ($1 \le c_i \le w_i \le 10^4$, $1 \le f_i \le g$).

## Формат вывода

Выведите ответ на задачу.

## Решение

Условие «все цвета различны» означает, что из каждой группы одного цвета берётся не больше одного предмета - это рюкзак с группами.

Предметы раскладываются по цветам, и цвета обрабатываются по очереди. Внутри цвета вес перебирается по убыванию, поэтому все состояния, из которых берётся переход, относятся к предыдущему слою: любой предмет текущего цвета пристраивается к набору, где этого цвета ещё не было, и взять два предмета одного цвета невозможно.

Хранить весь двумерный массив не нужно - достаточно одномерного массива по вместимости, который переиспользуется на каждом цвете.

Итого $O(nm)$ времени и $O(m)$ памяти.
