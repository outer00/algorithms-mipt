# G. Числа-враги

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

В этой задаче натуральными числами считаются $1, 2, 3, \ldots$

Скажем, что два натуральных числа дружат, если они отличаются друг от друга **менее** чем вдвое. В противном случае числа враждуют.

Найдите количество множеств (не мультимножеств) натуральных чисел, таких что:

- любые два различных числа из множества **враждуют**;
- сумма всех чисел в множестве равна $n$.

## Формат ввода

Единственная строка содержит одно целое число $n$ ($1 \le n \le 2\,000$).

## Формат вывода

Выведите количество подходящих множеств.

## Решение

Если все числа множества попарно враждуют, то, упорядочив их по убыванию, получаем, что каждое следующее не больше половины предыдущего. Значит, множество однозначно строится жадным перебором сверху вниз.

$dp[s][x]$ - количество подходящих множеств с суммой $s$, все элементы которых не превосходят $x$. Переход разбирает наибольший допустимый элемент: либо $x$ не используется и остаётся $dp[s][x-1]$, либо $x$ берётся, и тогда остаток суммы набирается числами не больше $\lfloor x/2 \rfloor$. Если $x$ уже больше оставшейся суммы, ограничение сверху бесполезно и состояние сводится к $dp[s][s]$.

Ответ - $dp[n][n]$. Итого $O(n^2)$.
