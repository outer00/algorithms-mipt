# H. Числа-друзья

`2 с` · `512 МБ` · 4 балла · [решение](solution.cpp)

В этой задаче натуральными числами считаются $1, 2, 3, \ldots$

Скажем, что два натуральных числа дружат, если они отличаются друг от друга **менее** чем вдвое. В противном случае числа враждуют.

Найдите количество множеств (не мультимножеств) натуральных чисел, таких что:

- любые два различных числа из множества **дружат**;
- сумма всех чисел в множестве равна $n$.

## Формат ввода

Единственная строка содержит одно целое число $n$ ($1 \le n \le 2\,000$).

## Формат вывода

Выведите количество подходящих множеств.

## Решение

Все элементы попарно дружат тогда и только тогда, когда наибольший из них строго меньше удвоенного наименьшего. Поэтому множество полностью определяется своим минимумом: если минимум равен $m$, все остальные элементы различны и лежат в интервале $(m, 2m)$.

Минимум перебирается явно, и для каждого $m$ остаётся посчитать число подмножеств чисел $m+1, \ldots, 2m-1$ с фиксированной суммой $n - m$ - это классический подсчёт числа представлений суммы различными слагаемыми: одномерная динамика по сумме, где каждое слагаемое добавляется один раз, а перебор суммы идёт по убыванию. Заведомо недостижимые суммы отсекаются проверкой на максимальную возможную сумму интервала.

Множество из одного числа $\{n\}$ подходит всегда - оно учитывается отдельно, поскольку в переборе минимум всегда сопровождается хотя бы одним другим элементом.

Итого $O(n^2)$.
