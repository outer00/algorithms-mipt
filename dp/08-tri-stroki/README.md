# I. Три строки

`1 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

Редакторским расстоянием $\rho_e$ между двумя строками называется наименьшее количество вставок, удалений и замен символов, необходимых для того, чтобы сделать строки равными. Расстоянием Хэмминга $\rho_H$ между двумя строками равной длины называется количество позиций, в которых они различаются.

Даны строки $u$ и $v$, а также число $k$. Строку $w$ назовём хорошей, если выполнены оба условия:

1. $\rho_e(u, w) \le k$;
2. $|v| = |w|$.

Найдите $\min \rho_H(v, w)$ по всем хорошим строкам $w$.

## Формат ввода

Первая строка содержит строку $u$ ($1 \le |u| \le 1000$), состоящую из маленьких латинских букв.

Вторая строка содержит строку $v$ ($1 \le |v| \le 1000$), состоящую из маленьких латинских букв.

Третья строка содержит одно целое число $k$ ($0 \le k \le 20$).

## Формат вывода

Выведите ответ на задачу. Если хороших строк $w$ не существует, выведите $-1$.

## Решение

Ответ ищется от обратного: минимальное расстояние Хэмминга - это $|v|$ минус максимальное число позиций, в которых $w$ можно сделать совпадающей с $v$. Строка $w$ получается из $u$ не более чем $k$ правками, поэтому состояние динамики - сколько символов $u$ уже удалено и сколько вставлено: $dp[i][d][a]$ - максимум совпадений на префиксе $v$ длины $i$ при $d$ удалениях и $a$ вставках. Сдвиг между префиксами $u$ и $v$ однозначно определяется парой $(d, a)$, поэтому третья длина в состоянии не нужна.

Переходы: удалить очередной символ $u$, вставить символ (тогда его сразу выгодно поставить равным символу $v$, отсюда $+1$), либо оставить символ $u$ на своём месте, что даёт совпадение только при равенстве символов.

Оставшийся бюджет правок $k - d - a$ можно потратить на замены: каждая замена чинит одну позицию, поэтому он добавляется к числу совпадений с ограничением сверху длиной $v$. Финальный ответ перебирает пары $(d, a)$, при которых длина результата совпадает с $|u|$. Если $|u|$ и $|v|$ различаются больше чем на $k$, хороших строк нет вовсе.

Итого $O(|v| \cdot k^2)$.
