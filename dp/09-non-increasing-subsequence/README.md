# K. Невозрастающая подпоследовательность

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Найдите наибольшую невозрастающую подпоследовательность в данном массиве.

Формально, дан массив $a_1, a_2, \ldots, a_n$. Найдите последовательность $(i_1, i_2, \ldots, i_k)$ максимальной длины, такую что $i_1 < i_2 < \ldots < i_k$ и при этом $a_{i_1} \ge a_{i_2} \ge \ldots \ge a_{i_k}$.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 250\,000$).

Вторая строка содержит $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($|a_i| \le 2^{31} - 2$).

## Формат вывода

Сначала выведите длину найденной подпоследовательности, а затем список её индексов. Если существует несколько решений, выведите любое.

## Решение

Классический алгоритм за $O(n \log n$): поддерживается массив, в $j$-й позиции которого лежит индекс элемента, завершающего наилучшую (с максимальным последним значением) невозрастающую подпоследовательность длины $j + 1$. Значения в этом массиве невозрастают, поэтому позицию очередного элемента находит бинарный поиск с обратным сравнением.

Если элемент не влезает ни в одну из позиций, он удлиняет ответ на единицу, иначе - улучшает существующую позицию. В обоих случаях запоминается предок: элемент, стоящий на предыдущей позиции массива в момент вставки. Сама подпоследовательность восстанавливается по цепочке предков от последнего элемента.

В массиве хранятся именно индексы, а не значения, - иначе восстановить ответ было бы нельзя.

Итого $O(n \log n)$.
