# L. Маленькая лесенка

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Последовательность чисел $(b_1, b_2, \ldots, b_k)$ назовём лесенкой, если выполняется одно из двух условий:

- $b_1 < b_2 > b_3 < b_4 > \ldots$;
- $b_1 > b_2 < b_3 > b_4 < \ldots$.

Дан массив $a_1, a_2, \ldots, a_n$. Найдите в нём самую длинную подпоследовательность, являющуюся лесенкой.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 2\,000$).

Вторая строка содержит $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($|a_i| \le 2^{31} - 2$).

## Формат вывода

В первой строке выведите длину наибольшей лесенки. Во второй строке выведите значения элементов, образующих её. Если решений несколько, выведите любое.

## Решение

Для каждой позиции хранятся два значения: длина лучшей лесенки, заканчивающейся в ней шагом вверх, и длина лучшей, заканчивающейся шагом вниз. Переход перебирает предыдущий элемент: если он меньше текущего, шаг вверх продолжает лесенку, заканчивавшуюся шагом вниз, и наоборот. Так чередование поддерживается автоматически.

Ответ - максимум по обоим значениям всех позиций. Для восстановления рядом с длинами хранятся предки, тоже отдельно для шага вверх и шага вниз; при подъёме по цепочке направление шага чередуется вместе с ней.

Итого $O(n^2)$ - на $n \le 2000$ этого достаточно.
