# M. Большая лесенка

`2.5 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Последовательность чисел $(b_1, b_2, \ldots, b_k)$ назовём лесенкой, если выполняется одно из двух условий:

- $b_1 < b_2 > b_3 < b_4 > \ldots$;
- $b_1 > b_2 < b_3 > b_4 < \ldots$.

Дан массив $a_1, a_2, \ldots, a_n$. Найдите в нём самую длинную подпоследовательность, являющуюся лесенкой.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 5 \cdot 10^5$).

Вторая строка содержит $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($|a_i| \le 2^{31} - 2$).

## Формат вывода

В первой строке выведите длину наибольшей лесенки. Во второй строке выведите значения элементов, образующих её. Если решений несколько, выведите любое.

## Решение

Та же задача, что и в «Маленькой лесенке», но квадратичная динамика уже не проходит по времени, поэтому используется жадный проход за $O(n)$.

Достаточно смотреть только на соседние элементы массива: строгий подъём $a_{i-1} < a_i$ удлиняет лучшую лесенку, заканчивающуюся спуском, а строгий спуск - лучшую, заканчивающуюся подъёмом. Равные соседние элементы не делают ничего. Это корректно, потому что в любой оптимальной лесенке между двумя выбранными элементами обязательно найдётся соседняя пара с нужным направлением.

Поддерживаются два ответа-кандидата - заканчивающиеся подъёмом и спуском; при удлинении одного из них второй достраивается до общей части. В конце берётся более длинный.

Итого $O(n)$.
