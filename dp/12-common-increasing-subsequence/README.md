# N. Общая возрастающая подпоследовательность

`1 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

Даны два массива чисел. Найдите их наибольшую общую возрастающую подпоследовательность.

Формально, даны $a_1, a_2, \ldots, a_n$ и $b_1, b_2, \ldots, b_m$. Найдите наибольшее $k$, для которого существуют такие $1 \le i_1 < i_2 < \ldots < i_k \le n$ и $1 \le j_1 < j_2 < \ldots < j_k \le m$, что:

- $a_{i_1} = b_{j_1}, a_{i_2} = b_{j_2}, \ldots, a_{i_k} = b_{j_k}$;
- $a_{i_1} < a_{i_2} < \ldots < a_{i_k}$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n, m \le 3\,000$).

Вторая строка содержит $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($|a_i| \le 10^9$).

Третья строка содержит $m$ целых чисел $b_1, b_2, \ldots, b_m$ ($|b_j| \le 10^9$).

## Формат вывода

Выведите одно число $k$ - длину наибольшей общей возрастающей подпоследовательности массивов $a$ и $b$.

## Решение

$dp[i][j]$ - длина наибольшей общей возрастающей подпоследовательности, использующей первые $i$ элементов $a$ и заканчивающейся ровно на $b_j$. Прямой перебор предыдущего элемента дал бы $O(nm^2)$, что не проходит по времени, поэтому используется стандартный приём: при фиксированном $i$ проход по $j$ идёт слева направо и по дороге поддерживается `best` - максимум $dp[i-1][j']$ по уже просмотренным позициям с $b_{j'} < a_i$.

Тогда при $a_i = b_j$ ответ в клетке равен `best + 1`, а иначе просто наследуется сверху. Условие $b_{j'} < a_i$ вместе с $a_i = b_j$ даёт нужное возрастание, а порядок обхода гарантирует $j' < j$.

Итого $O(nm)$ времени.
