# O. Различные подпоследовательности

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дана последовательность из $n$ чисел. Найдите количество её различных непустых подпоследовательностей. Поскольку ответ может быть очень большим, выведите его по модулю $10^9 + 7$.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 3 \cdot 10^5$).

Вторая строка содержит $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($1 \le a_i \le 10^6$).

## Формат вывода

Выведите количество различных непустых подпоследовательностей массива $a$ по модулю $10^9 + 7$.

## Решение

$dp[i]$ - количество различных подпоследовательностей первых $i$ элементов, включая пустую. Каждую из них можно либо оставить как есть, либо дописать в конец $a_i$, поэтому первым приближением идёт $dp[i] = 2 \cdot dp[i-1]$.

Это удваивание считает лишнее, если значение $a_i$ уже встречалось. Пусть предыдущее вхождение было на позиции $p$: подпоследовательности, полученные приписыванием $a_i$ к чему-то из первых $p-1$ элементов, уже были получены приписыванием того же значения на позиции $p$. Таких повторов ровно $dp[p-1]$, они и вычитаются. Позиции предыдущих вхождений хранятся в словаре.

В конце вычитается единица за пустую подпоследовательность. Итого $O(n \log n)$ из-за словаря.
