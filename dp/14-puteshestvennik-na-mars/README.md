# P. Путешественник на Марс

`1 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

Поверхность Марса можно представить в виде плоскости с декартовой системой координат. Движение по Марсу очень ограниченно: из точки $(x, y)$ переместиться можно только в точки $(x, y - 1)$ и $(x + 1, y - 1)$.

На Марсе расположено $n$ лётных площадок. До $i$-й из них с Земли можно добраться любым из $k_i$ космических рейсов. Также на Марсе есть $q$ волшебных прямых, задаваемых уравнениями $y = x + c_j$.

Маршрут путешественника: выбирается одна из площадок, путешественник прилетает на неё одним из доступных рейсов, а затем, двигаясь по поверхности, доходит до произвольной точки на прямой.

Для каждой прямой определите число различных способов добраться с Земли до этой прямой по модулю $10^9 + 9$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $q$ ($1 \le n, q \le 300$).

В $i$-й из следующих $n$ строк содержатся три числа $x_i$, $y_i$ и $k_i$ ($|x_i| \le 10^{18}$, $|y_i| \le 10^{18}$, $1 \le k_i \le 10^{18}$).

В $j$-й из следующих $q$ строк содержится одно целое число $c_j$ ($|c_j| \le 10^{18}$), задающее прямую $y = x + c_j$.

## Формат вывода

Для каждой прямой выведите количество способов добраться до неё по модулю $10^9 + 9$.

## Решение

Обе разрешённые подвижки уменьшают $y$ на единицу, а разность $y - x$ уменьшается на $1$ или на $2$. Значит, число маршрутов из точки до прямой $y = x + c$ зависит только от величины $h = y - x - c$ - начального «расстояния» по этой разности. Число способов представить $h$ в виде упорядоченной суммы единиц и двоек равно числу Фибоначчи $F_{h+1}$, поэтому вклад площадки равен $k_i \cdot F_{h+1}$, а площадки с $h < 0$ до прямой не дотягиваются вовсе.

Само число Фибоначчи с индексом до $2 \cdot 10^{18}$ считается быстрым удвоением: одна рекурсия по битам $n$ возвращает пару $(F_n, F_{n+1})$ и получает следующую пару по формулам удвоения за $O(\log n)$ умножений по модулю.

Итого $O(nq \log C)$.
