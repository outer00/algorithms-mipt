# Q. Путешественник на Венеру

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Поверхность Венеры можно представить в виде плоскости с декартовой системой координат. Из точки $(x, y)$ сдвигаться можно только в точки $(x + 1, y - 1)$, $(x + 1, y)$, $(x + 1, y + 1)$. Более того, на плоскости остались только точки с неотрицательными координатами.

Путешественник уже прибыл в точку $(0, 0)$ и хочет добраться до точки $(k, 0)$.

Также есть $n$ дополнительных условий: $i$-е из них задаётся горизонтальным отрезком $(a_i, c_i)$ - $(b_i, c_i)$ и запрещает находиться в точках над ним. Формально, если для какой-то точки пути $x \in [a_i, b_i]$, то $y \in [0, c_i]$. Гарантируется, что $a_1 = 0$, $b_i = a_{i+1}$, $b_n = k$.

Определите количество путей, удовлетворяющих всем ограничениям, по модулю $10^9 + 7$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $k$ ($1 \le n \le 100$, $1 \le k \le 10^{18}$).

В $i$-й из следующих $n$ строк содержится три числа $a_i$, $b_i$, $c_i$ ($0 \le a_i < b_i \le k$, $0 \le c_i \le 16$), задающие $i$-е условие.

## Формат вывода

Выведите количество путей из $(0, 0)$ в $(k, 0)$, удовлетворяющих всем ограничениям, по модулю $10^9 + 7$.

## Решение

Высота ограничена шестнадцатью, а длина пути - $10^{18}$, поэтому динамика ведётся по высоте, а движение вдоль $x$ ускоряется возведением матрицы в степень.

Внутри одного участка с потолком $c$ переход за один шаг - это матрица $17 \times 17$, в которой из высоты $j$ разрешены переходы в $j - 1$, $j$ и $j + 1$, обрезанные по границам $0$ и $c$. Проход всего участка длины $b_i - a_i$ - это та же матрица в соответствующей степени, которая считается быстрым возведением за $O(c^3 \log k)$.

Вектор распределения высот на границе участка умножается на матрицу участка и становится входом для следующего. Потолки могут отличаться, поэтому матрица строится для каждого участка заново, а высоты выше текущего потолка автоматически обнуляются. Ответ - количество путей, оставшееся в нулевой высоте после последнего участка.

Итого $O(n c^3 \log k)$.
