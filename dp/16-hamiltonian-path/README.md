# R. Гамильтон

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан полный неориентированный взвешенный граф. Найдите в нём самый дешёвый гамильтонов путь.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 13$) - количество вершин в графе.

Следующие $n$ строк содержат описание весов рёбер: в $i$-й строке содержатся $n$ целых чисел $a_{i1}, a_{i2}, \ldots, a_{in}$ ($0 \le a_{ij} \le 10^6$), где $a_{ij}$ - вес ребра из $i$-й вершины в $j$-ю. Гарантируется, что $a_{ii} = 0$ и $a_{ij} = a_{ji}$.

## Формат вывода

В первой строке выведите длину самого дешёвого гамильтонова пути.

Во второй строке выведите последовательность из $n$ различных чисел - порядок, в котором путь обходит все вершины.

## Решение

Динамика по подмножествам: $dp[\text{mask}][v]$ - минимальный вес пути, который посетил ровно вершины из маски и закончился в $v$. База - путь из одной вершины, переход добавляет непосещённую вершину в конец.

Ответ - минимум по последней вершине среди полных масок. Порядок обхода восстанавливается по массиву предков: зная маску и последнюю вершину, предыдущая вершина берётся из `parent`, а сама вершина убирается из маски.

Итого $O(2^n n^2)$ времени и $O(2^n n)$ памяти, чего при $n \le 13$ достаточно.
