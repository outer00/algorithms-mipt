# S. Сбалансированная табличка

`1.5 с` · `16 МБ` · 4 балла · [решение](solution.cpp)

Обратите внимание на необычное ограничение по памяти.

Рассмотрим прямоугольную таблицу $n \times m$. Её клетки нужно заполнить знаками «+» и «-». Некоторые клетки уже заполнены, остальные помечены символом «.».

Назовём таблицу сбалансированной, если в каждом её квадрате размера $2 \times 2$ содержится поровну плюсов и минусов.

Определите число способов заполнить таблицу так, чтобы она стала сбалансированной, по модулю $10^9 + 7$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 15$, $1 \le m \le 100$).

Каждая из следующих $n$ строк содержит описание очередной строки таблицы из $m$ символов «+», «-» или «.».

## Формат вывода

Выведите количество способов заполнить таблицу так, чтобы она стала сбалансированной, по модулю $10^9 + 7$.

## Решение

Столбец кодируется битовой маской длины $n$, а динамика идёт по столбцам: $dp[\text{mask}]$ - число способов заполнить префикс таблицы так, что последний столбец равен маске.

Ключевое наблюдение сокращает перебор переходов до двух: если два соседних столбца сбалансированы, то следующий столбец либо полностью повторяет предыдущий, либо полностью ему противоположен. Действительно, в каждом квадрате $2 \times 2$ сумма четырёх бит равна двум, поэтому пара соседних бит нового столбца однозначно определяется парой предыдущего. Поэтому из каждой маски есть ровно два кандидата, и оба проверяются на совместимость с уже заполненными клетками и на сбалансированность.

Ограничение памяти в 16 МБ не позволяет хранить всю таблицу динамики $2^n \times m$, поэтому в памяти живут только два слоя, которые меняются местами после каждого столбца.

Итого $O(2^n (n + m))$ времени и $O(2^n)$ памяти.
