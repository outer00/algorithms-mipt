# T. Красивая табличка

`3 с` · `256 МБ` · 4 балла · [решение](solution.cpp)

Рассмотрим прямоугольную таблицу $n \times m$. Её клетки нужно заполнить нулями и единицами.

Назовём таблицу красивой, если в каждом её квадрате размера $2 \times 2$ хотя бы один раз встречается единица и хотя бы один раз встречается ноль.

Определите число способов заполнить таблицу так, чтобы она стала красивой, по модулю $z$.

## Формат ввода

Единственная строка содержит три целых числа $n$, $m$ и $z$ ($1 \le n \le 10^{100}$, $1 \le m \le 6$, $1 \le z \le 10^4$).

## Формат вывода

Выведите количество красивых таблиц размера $n \times m$, взятое по модулю $z$.

## Решение

Строка таблицы кодируется маской из $m$ бит, а условие красивости связывает только соседние строки: пара масок допустима, если ни в одном из $m - 1$ квадратов $2 \times 2$ все четыре бита не одинаковы. Число способов продолжить таблицу зависит только от последней строки, поэтому задача - это подсчёт путей длины $n - 1$ в графе на $2^m \le 64$ вершинах, то есть степень матрицы смежности.

Число строк доходит до $10^{100}$ и в стандартные типы не влезает, поэтому показатель степени хранится в самописной длинной арифметике: двоичное возведение в степень делит его пополам обычным делением, а чётность проверяется по младшему разряду. Длинная арифметика написана с нуля: сложение и вычитание в столбик по основанию $10^9$, умножение наивное, деление уголком с подбором очередной цифры частного бинарным поиском.

Ответ - сумма всех элементов итоговой матрицы: он суммирует пути по всем парам «первая строка - последняя строка».

Итого $O(8^m \log n)$ умножений по модулю.
