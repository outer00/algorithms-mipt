# U. Клики

`2 с` · `512 МБ` · 3 балла · [решение](solution.cpp)

Неориентированный граф на $n$ вершинах задан своей матрицей смежности. Найдите количество клик в нём (включая пустое множество).

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 50$).

Следующие $n$ строк содержат матрицу смежности графа: в $i$-й строке $j$-й символ равен «1», если вершины $i$ и $j$ соединены ребром, иначе «0». Гарантируется, что матрица симметрична и на её главной диагонали стоят нули.

## Формат вывода

Выведите количество клик в заданном графе.

## Решение

Перебрать все $2^{50}$ подмножеств нельзя, поэтому применяется встреча посередине: вершины делятся на две половины примерно по $25$, и каждая клика раскладывается на свою левую и правую части.

Для каждой маски одной половины считается пересечение окрестностей её вершин - множество вершин, смежных со всеми выбранными. Пересечение считается инкрементально: маска получается из меньшей на один бит, поэтому достаточно одного «и» со строкой матрицы смежности. Маска является кликой ровно тогда, когда она вложена в собственное пересечение окрестностей.

Для правой половины дополнительно хранится пересечение окрестностей в левой половине: клика с данной правой частью дополняется любым подмножеством этого пересечения, которое само является кликой. Число таких подмножеств для каждой маски левой половины заранее насчитывается суммированием по подмаскам (SOS-динамика) за $O(2^{n/2} \cdot n)$.

Итого $O(2^{n/2} \cdot n)$ времени и памяти.
