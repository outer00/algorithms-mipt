# Динамическое программирование

Классические задачи на динамику: рюкзаки, подпоследовательности, динамика по подмножествам и по профилю, ускорение переходов матричным возведением в степень.

| # | Задача | Идея решения | Сложность |
|---|--------|--------------|-----------|
| 01 | [Много колодцев](01-mnogo-kolodcev/) | Динамика по числу колодцев, стоимость перехода через префиксные суммы | $O(mn^2)$ |
| 02 | [Хрустальный шар](02-hrustalnyj-shar/) | Динамика по шарам и этажам, минимум максимума бинарным поиском | $O(n \log^2 n)$ |
| 03 | [LCS](03-lcs/) | Наибольшая общая подпоследовательность с восстановлением ответа | $O(nm)$ |
| 04 | [Рюкзак](04-knapsack/) | Рюкзак 0-1 с восстановлением набора | $O(nm)$ |
| 05 | [Цветной рюкзак](05-colored-knapsack/) | Рюкзак с группами, один слой по вместимости | $O(nm)$ |
| 06 | [Числа-враги](06-chisla-vragi/) | Динамика по сумме и верхней границе элемента | $O(n^2)$ |
| 07 | [Числа-друзья](07-chisla-druzya/) | Перебор минимума + разбиения на различные слагаемые | $O(n^2)$ |
| 08 | [Три строки](08-tri-stroki/) | Динамика по префиксу и бюджету правок | $O(nk^2)$ |
| 09 | [Невозрастающая подпоследовательность](09-non-increasing-subsequence/) | Массив хвостов + бинарный поиск, восстановление по предкам | $O(n \log n)$ |
| 10 | [Маленькая лесенка](10-malenkaya-lesenka/) | Квадратичная динамика по направлению последнего шага | $O(n^2)$ |
| 11 | [Большая лесенка](11-bolshaya-lesenka/) | Жадный проход по соседним элементам | $O(n)$ |
| 12 | [Общая возрастающая подпоследовательность](12-common-increasing-subsequence/) | Динамика с поддержкой лучшего префикса на лету | $O(nm)$ |
| 13 | [Различные подпоследовательности](13-distinct-subsequences/) | Удвоение с вычитанием повторов по предыдущему вхождению | $O(n \log n)$ |
| 14 | [Путешественник на Марс](14-puteshestvennik-na-mars/) | Числа Фибоначчи быстрым удвоением | $O(nq \log C)$ |
| 15 | [Путешественник на Венеру](15-puteshestvennik-na-veneru/) | Динамика по высоте, участки - возведение матрицы в степень | $O(nc^3 \log k)$ |
| 16 | [Гамильтон](16-hamiltonian-path/) | Динамика по подмножествам с восстановлением пути | $O(2^n n^2)$ |
| 17 | [Сбалансированная табличка](17-sbalansirovannaya-tablichka/) | Профильная динамика, два слоя из-за лимита в 16 МБ | $O(2^n(n+m))$ |
| 18 | [Красивая табличка](18-krasivaya-tablichka/) | Матрица переходов в степени $10^{100}$ на длинной арифметике | $O(8^m \log n)$ |
| 19 | [Клики](19-cliques/) | Встреча посередине + суммирование по подмаскам | $O(2^{n/2} n)$ |
