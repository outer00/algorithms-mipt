# C. Минимальное вершинное покрытие

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дан неориентированный двудольный граф и максимальное паросочетание в нём. Найдите в этом графе минимальное вершинное покрытие.

## Формат ввода

Первая строка содержит два целых числа $n$ и $k$ ($1 \le n, k \le 4000$) - размеры левой и правой доли.

Следующие $n$ строк задают рёбра графа: в $i$-й из них сначала записано целое число $m_i$, после которого записаны $m_i$ целых чисел - номера вершин правой доли, соединённых ребром с $i$-й вершиной левой доли.

Последняя строка содержит $n$ целых чисел $v_1, v_2, \ldots, v_n$ ($0 \le v_i \le k$), где $v_i$ задаёт номер вершины правой доли, соответствующей вершине $i$ левой доли в паросочетании. Если вершина $i$ не насыщена, то $v_i = 0$.

Гарантируется, что общее число рёбер не превосходит $5 \cdot 10^5$.

## Формат вывода

В первой строке выведите число вершин в минимальном вершинном покрытии.

Во второй строке - число вершин левой доли, взятых в покрытие, и затем их номера.

В третьей строке - число вершин правой доли, взятых в покрытие, и затем их номера.

## Решение

Теорема Кёнига: в двудольном графе размер минимального вершинного покрытия равен размеру максимального паросочетания, а само покрытие строится из паросочетания.

Граф ориентируется: рёбра вне паросочетания направляются из левой доли в правую, рёбра паросочетания - обратно. Из всех ненасыщенных вершин левой доли запускается обход в глубину. В покрытие берутся непосещённые вершины левой доли и посещённые вершины правой: любое ребро оказывается покрыто, потому что обход, дойдя до левого конца ребра, обязательно пройдёт по нему направо.

Ненасыщенные вершины отбрасываются автоматически - обход стартует из них, поэтому они помечены. Итого $O(V + E)$.
