# D. Покрытие путями

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дан ориентированный ациклический граф с $n$ вершинами и $m$ рёбрами. Все его вершины нужно покрыть непересекающимися путями. Определите минимальное необходимое число путей.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($2 \le n \le 10^3$, $0 \le m \le 10^5$).

Следующие $m$ строк содержат по два целых числа $u$ и $v$ ($1 \le u, v \le n$), задающих ребро из вершины $u$ в вершину $v$.

## Формат вывода

Выведите минимальное необходимое число путей, чтобы покрыть все вершины ровно по одному разу.

## Решение

Классическое сведение: каждая вершина исходного графа дублируется в левую и правую доли, ребро $u \to v$ становится ребром между левой копией $u$ и правой копией $v$. Ребро, взятое в паросочетание, означает «в покрытии за $u$ сразу идёт $v$», а условие непересекаемости путей - это ровно ограничение паросочетания: у каждой вершины не больше одного преемника и не больше одного предшественника.

Каждое ребро паросочетания склеивает два пути в один, поэтому ответ равен $n$ минус размер максимального паросочетания. В коде это считается напрямую: число вершин правой доли, оставшихся ненасыщенными после алгоритма Куна, - это и есть число начал путей.

Итого $O(V \cdot E)$.
