# E. Алгоритм Форда-Фалкерсона

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дан ориентированный граф с $n$ вершинами и $m$ рёбрами, каждому ребру которого предписана некоторая пропускная способность. Найдите в этом графе максимальный поток из вершины $1$ в вершину $n$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($2 \le n \le 100$, $1 \le m \le 1000$).

Каждая из следующих $m$ строк содержит три целых числа $u$, $v$ и $c$ ($1 \le u, v \le n$, $0 \le c \le 10^5$), задающих ребро из $u$ в $v$ пропускной способности $c$.

## Формат вывода

Выведите величину максимального потока из вершины $1$ в вершину $n$.

## Решение

Форд-Фалкерсон на матрице пропускных способностей: $n \le 100$, поэтому матрица $n \times n$ дешевле списков смежности и заодно бесплатно даёт обратные рёбра.

Поиск в глубину идёт по рёбрам с положительным остатком и возвращает узкое место найденного пути (или $0$, если пути нет). Возврат из рекурсии обновляет остаточную сеть по всему пути: прямое ребро уменьшается на величину потока, обратное увеличивается на неё же - благодаря этому алгоритм может «отменить» неудачное решение на следующих итерациях.

Внешний цикл повторяет поиск, пока увеличивающий путь находится. Итого $O(F \cdot n^2)$, где $F$ - величина максимального потока.
