# K. Максимальный поток минимальной стоимости

`1 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

Дан ориентированный граф с $n$ вершинами и $m$ рёбрами. У каждого ребра задана пропускная способность и стоимость переправки по нему одной единицы товара.

Найдите в этом графе максимальный поток минимальной стоимости из вершины $1$ в вершину $n$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($2 \le n \le 100$, $0 \le m \le 1000$).

Каждая из следующих $m$ строк содержит четыре целых числа $u, v, c, w$ ($1 \le u, v \le n$, $0 \le c, w \le 10^5$), задающих ребро из вершины $u$ в вершину $v$ с пропускной способностью $c$ и стоимостью $w$.

## Формат вывода

Выведите одно число - минимальную стоимость максимального потока из $1$ в $n$.

## Решение

Поиск кратчайших путей по стоимости с последующим насыщением: пока в остаточной сети есть путь из $1$ в $n$, поток проталкивается по самому дешёвому из них.

Рёбра лежат в одном массиве парами: за прямым ребром сразу идёт обратное с нулевой пропускной способностью и противоположной стоимостью, поэтому парное ребро находится как `i ^ 1`. Из-за отрицательных стоимостей на обратных рёбрах Дейкстра неприменима, кратчайшие пути ищутся алгоритмом Беллмана-Форда за $n - 1$ проход по всем рёбрам, попутно запоминая, каким ребром вершина была улучшена.

По цепочке `prev_edge` восстанавливается путь, по нему считается узкое место, затем поток проталкивается и стоимость накапливается. Когда сток становится недостижим, поток максимален, а его стоимость минимальна.

Итого $O(F \cdot nm)$.
