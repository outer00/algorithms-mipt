# Потоки и паросочетания

Двудольные паросочетания (Кун), сведения к ним, максимальный поток и минимальный разрез.

| # | Задача | Идея решения | Сложность |
|---|--------|--------------|-----------|
| 01 | [Двудольное паросочетание](01-bipartite-matching/) | Алгоритм Куна | $O(VE)$ |
| 02 | [Доминошки и квадраты](02-dominoshki-i-kvadraty/) | Шахматная раскраска → паросочетание, выбор между доминошкой и парой квадратов | $O(VE)$ |
| 03 | [Минимальное вершинное покрытие](03-minimum-vertex-cover/) | Теорема Кёнига: обход из ненасыщенных вершин | $O(V + E)$ |
| 04 | [Покрытие путями](04-path-cover/) | Сведение к паросочетанию: ответ $= n -$ размер паросочетания | $O(VE)$ |
| 05 | [Алгоритм Форда-Фалкерсона](05-ford-fulkerson/) | Увеличивающие пути поиском в глубину по матрице | $O(Fn^2)$ |
| 06 | [Минимальный разрез](06-minimum-cut/) | Максимальный поток + разметка достижимости в остаточной сети | $O(Fn^2)$ |
| 07 | [Поток минимальной стоимости](07-mincost-maxflow/) | Беллман-Форд по остаточной сети с отрицательными стоимостями | $O(Fnm)$ |
