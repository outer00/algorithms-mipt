# B. Компоненты связности

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан неориентированный граф с $n$ вершинами и $m$ рёбрами. Выделите его компоненты связности.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).

Следующие $m$ строк содержат описание рёбер: два целых числа $u$ и $v$ ($1 \le u, v \le n$), задающих ребро между вершинами $u$ и $v$.

## Формат вывода

В первой строке выведите количество компонент связности в заданном графе.

Затем в произвольном порядке выведите сами компоненты: сначала количество вершин в компоненте, а затем перечислите эти вершины.

## Решение

Обход в глубину из каждой ещё не посещённой вершины. Номер текущей компоненты передаётся в рекурсию, и каждая вершина по дороге приписывается к нему, поэтому списки компонент собираются прямо во время обхода, без второго прохода по графу.

Итого $O(V + E)$.
