# C. Топологическая сортировка

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан ориентированный граф с $n$ вершинами и $m$ рёбрами. Необходимо его топологически отсортировать или определить, что это сделать невозможно.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 10^5$, $0 \le m \le 10^5$).

Следующие $m$ строк содержат описание рёбер: два целых числа $u$ и $v$ ($1 \le u, v \le n$), задающих ребро из вершины $u$ в вершину $v$.

## Формат вывода

Если топологическая сортировка существует, выведите любую из них как последовательность вершин. Если её не существует, выведите одно число $-1$.

## Решение

Обход в глубину с тремя цветами. Ребро в серую вершину означает цикл - тогда топологической сортировки не существует и ответ $-1$.

Если циклов нет, порядок задаётся временами выхода: вершина покидается только после всех своих потомков, поэтому сортировка вершин по убыванию времени выхода и есть топологический порядок.

Итого $O(V + E)$ на обход и $O(V \log V)$ на сортировку по временам выхода.
