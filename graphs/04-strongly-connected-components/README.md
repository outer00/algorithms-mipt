# D. Компоненты сильной связности

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан ориентированный граф с $n$ вершинами и $m$ рёбрами. В нём могут быть петли и кратные рёбра.

Необходимо выделить в нём компоненты сильной связности и топологически отсортировать его конденсацию: все вершины нужно разбить на компоненты сильной связности, а сами компоненты пронумеровать последовательными числами, начиная с $1$, так, чтобы рёбра вели только из компонент с меньшими номерами в компоненты с большими номерами.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 5 \cdot 10^5$, $1 \le m \le 5 \cdot 10^5$).

Следующие $m$ строк содержат описание рёбер: два целых числа $u$ и $v$ ($1 \le u, v \le n$), задающих ребро из вершины $u$ в вершину $v$.

## Формат вывода

В первой строке выведите количество компонент сильной связности. Во второй строке выведите номера компонент для каждой вершины.

## Решение

Алгоритм Косарайю в два прохода. Первый обход по исходному графу заполняет времена выхода; вершины, отсортированные по убыванию этого времени, дают порядок, в котором компоненты идут топологически.

Второй обход идёт по транспонированному графу в этом порядке: каждый запуск из непосещённой вершины ровно накрывает одну компоненту сильной связности, потому что в обратном графе из неё достижимы только вершины своей компоненты и уже обработанных компонент. Нумерация компонент по порядку запусков сразу даёт требуемую топологическую нумерацию конденсации.

Оба прохода - один и тот же обход с флагом направления, чтобы не дублировать код.

Итого $O(V + E)$ на обходы и $O(V \log V)$ на сортировку.
