# E. Мосты

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дан неориентированный граф с $n$ вершинами и $m$ рёбрами. Ребро называется мостом, если его удаление увеличивает число компонент связности графа. Найдите все мосты графа.

В графе могут быть кратные рёбра и петли.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 2 \cdot 10^4$, $1 \le m \le 2 \cdot 10^5$).

Следующие $m$ строк содержат описание рёбер. В $i$-й из них два целых числа $u_i$ и $v_i$ ($1 \le u_i, v_i \le n$), задающих ребро между вершинами $u_i$ и $v_i$.

## Формат вывода

В первой строке выведите количество мостов в данном графе.

Во второй строке выведите номера рёбер, являющихся мостами, в порядке возрастания.

## Решение

Обход в глубину с функцией $\mathrm{low}$ - минимальным временем входа, достижимым из поддерева вершины по обратным рёбрам. Ребро дерева обхода в вершину $to$ является мостом, когда $\mathrm{low}[to] = \mathrm{tin}[to]$: из поддерева нет обратного пути в обход этого ребра.

Отдельно обрабатываются особенности условия. Петли выбрасываются при чтении - они никогда не мосты. Кратные рёбра нельзя пропустить через простую проверку «не идти к родителю», поэтому пары концов хранятся в словаре: при повторной вставке пары её номер помечается как $-1$, и такое ребро в ответ не попадает.

Итого $O((V + E)\log E)$ - логарифм из-за словаря номеров рёбер.
