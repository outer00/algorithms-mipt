# G. Сжечь мосты

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дан связный неориентированный граф с $n$ вершинами и $m$ рёбрами. Кратных рёбер и петель нет.

Определите, какое наименьшее число рёбер нужно добавить в этот граф, чтобы в нём не осталось мостов.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($3 \le n \le 5\,000$, $1 \le m \le 10^5$).

Следующие $m$ строк содержат описание рёбер: два целых числа $u$ и $v$ ($1 \le u, v \le n$), задающих ребро между вершинами $u$ и $v$.

## Формат вывода

Выведите наименьшее число рёбер, которое нужно добавить в граф, чтобы в нём не осталось мостов.

## Решение

Стянем каждую компоненту рёберной двусвязности в вершину - получится дерево мостов. Задача превращается в классическую: чтобы дерево стало рёберно двусвязным, нужно добавить $\lceil L / 2 \rceil$ рёбер, где $L$ - число листьев этого дерева.

Строить конденсацию явно не обязательно. Тот же обход в глубину с функцией $\mathrm{low}$ находит мосты, а лист дерева мостов - это мост, ниже которого в поддереве мостов больше нет. Поэтому обход возвращает признак «в поддереве уже был найден мост», и мост засчитывается в листья только при отрицательном ответе.

Корень обхода даёт лист отдельным случаем: он лист, если из него ведёт ровно одно ребро.

Итого $O((V + E)\log E)$.
