# H. Система уравнений

`2 с` · `512 МБ` · 2 балла · [решение](solution.cpp)

Дан связный неориентированный граф с $n$ вершинами и $m$ рёбрами. Каждой вершине $v$ сопоставлено число $x_v$; известно, что числа $x_1, x_2, \ldots, x_n$ образуют перестановку чисел $1, 2, \ldots, n$, но сами значения неизвестны.

Если ребро соединяет вершины $u$ и $v$, то на ребре записано число $x_u + x_v$. По информации о числах, записанных на рёбрах, восстановите значения $x_1, x_2, \ldots, x_n$. Если решений несколько, выведите любое.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n, m \le 10^6$).

Следующие $m$ строк содержат описание рёбер: три целых числа $u$, $v$ и $s$ ($1 \le u, v \le n$, $u \ne v$, $3 \le s \le 2n - 1$), задающих ребро между $u$ и $v$, на котором записано $s = x_u + x_v$.

## Формат вывода

Выведите значения $x_1, x_2, \ldots, x_n$, удовлетворяющие всем ограничениям. Если решений несколько, выведите любое.

## Решение

Граф связен, поэтому все значения выражаются через одно. Обход в глубину от первой вершины расставляет коэффициенты: соседи вершины с выражением $x_1 \cdot k + c$ получают $-k$ и $s - c$, то есть каждое $x_v$ равно либо $x_1 + c_v$, либо $-x_1 + c_v$.

Значения обязаны лежать в $[1, n]$, и это оставляет всего двух кандидатов на $x_1$: наименьшее допустимое значение из ограничений на вершины с коэффициентом $+1$ и симметричное ему для вершин с коэффициентом $-1$. Оба кандидата проверяются вторым обходом, который расставляет числа, следит за тем, чтобы значения не выходили из диапазона и не повторялись, и проверяет уже посещённые концы рёбер на согласованность суммы.

Итого $O(V + E)$.
