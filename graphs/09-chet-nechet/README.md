# I. Чёт-нечет

`2 с` · `512 МБ` · 2 балла · [решение](solution.cpp)

Дан неориентированный граф с $n$ вершинами и $m$ рёбрами. Изначально на каждом ребре написано число $0$ или $1$.

Далее в каждой вершине также записали число $0$ или $1$ по следующему правилу: если количество единиц, написанных на рёбрах, инцидентных данной вершине, нечётно, то в неё записывается $1$, иначе - $0$.

По числам, записанным в вершинах, определите, какие числа были записаны на рёбрах. Если решений несколько, выведите любое.

## Формат ввода

Каждый тест состоит из нескольких наборов входных данных. В первой строке находится одно целое число $t$ ($1 \le t \le 10^6$) - количество наборов.

Первая строка каждого набора содержит два целых числа $n$ и $m$ ($2 \le n \le 10^6$, $1 \le m \le 10^6$).

Следующие $m$ строк содержат описание рёбер: два целых числа $u_i$ и $v_i$ ($1 \le u_i, v_i \le n$, $u_i \ne v_i$).

Последняя строка каждого набора содержит строку длины $n$ из нулей и единиц: $v$-й её элемент равен числу, записанному в $v$-й вершине.

Гарантируется, что сумма значений $n$ и сумма значений $m$ по всем наборам не превосходят $10^6$.

## Формат вывода

Если решения не существует, выведите $-1$.

Иначе выведите строку длины $m$ из нулей и единиц, $i$-й элемент которой равен числу на $i$-м ребре.

## Решение

Достаточно решить задачу на остовном лесе: все рёбра вне дерева обхода можно оставить нулями, потому что дерева хватает, чтобы обеспечить нужную чётность в каждой вершине.

Обход в глубину возвращает, нужна ли единица на ребре, ведущем к родителю. Значение считается снизу вверх: вершине нужна единица наверх, если её собственная метка не сходится с чётностью единиц, уже поставленных на рёбра к детям. Это однозначно определяет все рёбра дерева.

Корень остаётся без ребра наверх, поэтому если он тоже требует единицу, суммарная чётность в его компоненте нечётна, а такого набора рёбер не существует - ответ $-1$.

Наборов входных данных много, поэтому массивы заводятся один раз на максимум и очищаются ровно на использованном префиксе.

Итого $O(V + E)$ на набор.
