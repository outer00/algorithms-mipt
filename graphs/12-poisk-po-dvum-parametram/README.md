# C. Поиск по двум параметрам

`3 с` · `512 МБ` · 3 балла · [решение](solution.cpp)

Дан неориентированный взвешенный граф с $n$ вершинами и $m$ рёбрами. Каждое ребро характеризуется двумя параметрами - неотрицательным временем прохода и неотрицательной стоимостью.

Нужно добраться из $1$-й вершины в $n$-ю не более чем за $s$ единиц времени. Использовать самый быстрый путь необязательно - достаточно любого пути, укладывающегося в $s$. Из всех таких путей найдите самый дешёвый.

## Формат ввода

Первая строка содержит три целых числа $n$, $m$ и $s$ ($1 \le n \le 10^3$, $1 \le m \le 5 \cdot 10^4$, $0 \le t \le 10^3$).

Каждая из следующих $m$ строк содержит четыре целых числа $u, v, c, t$ ($1 \le u, v \le n$, $0 \le c \le 10^6$, $0 \le t \le 10^3$), задающих ребро между $u$ и $v$ стоимости $c$, проходимое за время $t$.

## Формат вывода

Если добраться из $1$-й вершины в $n$-ю за время $s$ невозможно, выведите $-1$.

Иначе в первой строке выведите минимальную стоимость такого пути, во второй - число посещённых вершин, в третьей - саму последовательность вершин.

## Решение

Состояние - пара «вершина, потраченное время», то есть Дейкстра по стоимости на расширенном графе из $n(s+1)$ вершин. Состояние кодируется одним числом $v \cdot (s+1) + t$, поэтому массивы стоимостей и предков одномерные.

Чтобы не разворачивать заведомо бесполезные состояния, сначала запускается вторая Дейкстра - от финиша по времени. Она даёт минимальное время, за которое из каждой вершины можно дойти до конца; переход отбрасывается, если потраченное время плюс время ребра плюс этот остаток уже превышает лимит. Это отсечение делает перебор состояний практичным.

Ответ - минимум стоимости среди состояний финишной вершины по всем допустимым временам; путь восстанавливается по массиву предков в пространстве состояний.

Итого $O(ns \log(ns) + ms)$.
