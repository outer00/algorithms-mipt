# D. Алгоритм Форда-Беллмана

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан ориентированный взвешенный граф с $n$ вершинами и $m$ рёбрами. Гарантируется, что в этом графе нет циклов отрицательного веса.

Найдите длины кратчайших путей из вершины $1$ до всех остальных.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 100$, $0 \le m \le 10^4$).

Каждая из следующих $m$ строк содержит три целых числа $u$, $v$ и $c$ ($1 \le u, v \le n$, $-100 \le c \le 100$), задающих ориентированное ребро из $u$ в $v$ стоимости $c$.

## Формат вывода

Выведите $n$ чисел - расстояния от вершины $1$ до вершин $1, 2, \ldots, n$ в этом порядке. Если до какой-то вершины пути не существует, выведите вместо расстояния число $30000$.

## Решение

Веса рёбер отрицательные, поэтому Дейкстра неприменима: используется Форд-Беллман. Кратчайший путь без отрицательных циклов содержит не более $n - 1$ ребра, поэтому достаточно $n - 1$ раз пройти по всему списку рёбер, релаксируя их.

Недостижимость кодируется значением $30000$, которое требуется вывести по условию. Оно же служит признаком «расстояние ещё не определено» - релаксация из такой вершины запрещена, иначе через недостижимые вершины протекли бы фиктивные пути (веса рёбер по модулю не больше $100$, а путь не длиннее $100$ рёбер, так что настоящее расстояние никогда не дотягивает до этого значения).

Итого $O(nm)$.
