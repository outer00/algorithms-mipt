# E. Отрицательный цикл

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дан ориентированный взвешенный граф с $n$ вершинами. Найдите в нём цикл отрицательного веса или сообщите, что такого цикла нет.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 100$).

Следующие $n$ строк содержат матрицу смежности графа: в $i$-й из них $n$ целых чисел $a_{i1}, a_{i2}, \ldots, a_{in}$ ($-10^4 \le a_{ij} \le 10^4$ или $a_{ij} = 10^5$), задающих веса рёбер из $i$-й вершины во все остальные. Значение $a_{ij} = 10^5$ означает, что ребра из $i$ в $j$ нет.

## Формат вывода

Если отрицательного цикла нет, выведите «NO».

Иначе в первой строке выведите «YES», во второй - количество вершин в цикле, в третьей - список вершин цикла в порядке обхода. Стартовая вершина должна быть равна конечной.

Если решений несколько, выведите любое.

## Решение

Форд-Беллман с нулевыми начальными расстояниями во всех вершинах - это эквивалент добавления фиктивного истока, соединённого со всеми вершинами рёбрами нулевого веса, и он позволяет искать отрицательный цикл сразу во всём графе, не перебирая стартовую вершину.

Делается $n$ проходов по рёбрам вместо $n - 1$. Если на последнем проходе ещё была релаксация, отрицательный цикл существует, а релаксированная вершина гарантированно достижима из него. Спуск по предкам на $n$ шагов приводит внутрь цикла, после чего цикл выписывается движением по предкам до возврата в ту же вершину.

Итого $O(n^3)$: рёбер в полной матрице $O(n^2)$, проходов $n$.
