# F. Вы не учёный, Мартин Алексеевич

`1 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

Дан ориентированный взвешенный граф с $n$ вершинами и $m$ рёбрами, описывающий карту дорог некоторой страны. Учёный хочет выступить с докладом в городах $a_1, a_2, \ldots, a_k$ именно в этом порядке, начиная путешествие в $a_1$. Между выступлениями он может заезжать в любые города, в том числе в другие города из списка.

При проезде по ребру настроение меняется на заданную величину. Учёный читает доклады в наилучшем возможном настроении, поэтому каждый раз выбирает маршрут, максимизирующий настроение к моменту следующего доклада.

Постройте список рёбер, которые нужно проехать при оптимальной стратегии, либо определите, что учёный может быть в сколь угодно хорошем настроении при чтении очередного доклада. Гарантируется, что хотя бы один подходящий маршрут существует.

## Формат ввода

Первая строка содержит три целых числа $n$, $m$ и $k$ ($1 \le n \le 100$, $1 \le m \le 10^4$, $2 \le k \le 10^4$).

Следующие $m$ строк содержат описание рёбер: $i$-я строка содержит три целых числа $u_i$, $v_i$ и $d_i$ ($1 \le u_i, v_i \le n$, $-10^5 \le d_i \le 10^5$) - ребро из $u_i$ в $v_i$, при проезде по которому настроение изменяется на $d_i$.

Последняя строка содержит $k$ целых чисел $a_1, a_2, \ldots, a_k$ ($1 \le a_i \le n$).

## Формат вывода

Если учёный может достичь сколь угодно хорошего настроения, выведите «`infinitely kind`».

Иначе в первой строке выведите количество рёбер, которые нужно проехать, во второй - их номера в порядке проезда.

## Решение

Максимизация настроения превращается в минимизацию, если взять веса с обратным знаком; тогда задача - кратчайшие пути между всеми парами, то есть Флойд. Вершин всего $100$, поэтому куб проходит спокойно, а пар «доклад - следующий доклад» может быть $10^4$, и попарные расстояния всё равно нужны для всех пар.

Кратные рёбра сворачиваются при чтении: остаётся самое выгодное. Вместе с расстоянием хранится предок - пара «предыдущая вершина, номер ребра», что позволяет выписать сам маршрут; при релаксации через промежуточную вершину предок копируется из соответствующей ячейки.

Отрицательный цикл в перевёрнутых весах - это возможность накручивать настроение бесконечно. После Флойда вершины на таких циклах находятся по условию $d_{xx} < 0$, и все пары, путь между которыми проходит через такую вершину, помечаются как бесконечно хорошие. Если хотя бы один перегон маршрута попал в эту категорию, ответ - «infinitely kind».

Итого $O(n^3 + k \cdot n)$.
