# G. Транзитивное замыкание

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан ориентированный невзвешенный граф $G$ с $n$ вершинами. Его транзитивным замыканием называется граф $G^*$ на том же множестве вершин, такой что в $G^*$ есть ребро из $u$ в $v$ тогда и только тогда, когда в $G$ есть путь из $u$ в $v$. Найдите матрицу смежности графа $G^*$.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 100$).

Следующие $n$ строк содержат матрицу смежности графа $G$: $i$-я строка содержит $n$ целых чисел $a_{i1}, a_{i2}, \ldots, a_{in}$ ($0 \le a_{ij} \le 1$), где $a_{ij} = 1$ тогда и только тогда, когда в $G$ есть ребро из $i$ в $j$. Гарантируется, что $a_{ii} = 1$ для всех вершин.

## Формат вывода

Выведите матрицу смежности транзитивного замыкания графа $G$.

## Решение

Алгоритм Уоршелла - тот же тройной цикл, что и у Флойда, только вместо сложения расстояний логическое «или»: путь из $i$ в $j$ есть, если он был раньше или если есть путь через промежуточную вершину $k$. Порядок циклов важен: внешний обязательно по промежуточной вершине.

Итого $O(n^3)$.
