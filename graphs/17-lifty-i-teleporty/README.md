# J. Лифты и телепорты

`2 с` · `256 МБ` · 3 балла · [решение](solution.cpp)

В небоскрёбе миллион этажей, пронумерованных числами от $1$ до $10^6$. Вы стоите на первом этаже и хотите попасть на $n$-й.

В здании есть лифт: подъём на один этаж вверх стоит $u$ рублей, спуск на один этаж вниз - $d$ рублей.

Кроме лифта есть телепорты, позволяющие перемещаться между некоторыми этажами. Всего есть $k$ телепортов, каждый соединяет некоторое множество этажей. Воспользоваться телепортом можно так: добраться до одного из этажей, на котором он есть, войти в него (потратив $i$ рублей), выбрать желаемый этаж, соединённый с этим телепортом, и выйти на нём (потратив $o$ рублей).

Найдите минимальную стоимость пути с $1$-го этажа до $n$-го.

## Формат ввода

Первая строка содержит шесть целых чисел $n, u, d, i, o, k$ ($1 \le n \le 10^6$, $0 \le u, d, i, o \le 10^3$, $0 \le k \le 500$).

Каждая из следующих $k$ строк содержит описание телепорта: число $t_i$ ($0 \le t_i \le 10^5$), за которым следует $t_i$ номеров этажей. Гарантируется, что $\sum t_i \le 10^5$.

## Формат вывода

Выведите минимальную стоимость пути.

## Решение

Наивный граф на миллионе этажей с рёбрами между соседними слишком велик, но интересны только этажи, где что-то происходит: старт, финиш и этажи телепортов - их не больше $10^5 + 2$. Между соседними интересными этажами лифт едет напрямую, и такое ребро стоит ровно $u$ или $d$, умноженное на разницу этажей.

Телепорты моделируются дополнительными вершинами: вход стоит $i$, выход - $o$. Это превращает клику из $t_i$ этажей в звезду с $2t_i$ рёбрами, иначе рёбер было бы квадратично.

Дальше обычная Дейкстра на `std::set`. Интересные этажи хранятся в упорядоченном множестве, поэтому «соседние» пары получаются одним проходом по нему.

Итого $O((n_{\text{этажей}} + \sum t_i) \log)$ по числу интересных вершин, а не по миллиону этажей.
