# M. MST

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан связный неориентированный взвешенный граф с $n$ вершинами и $m$ рёбрами. Найдите вес его минимального остовного дерева.

## Формат ввода

Первая строка содержит два целых числа $n$ и $m$ ($1 \le n \le 10^5$, $n - 1 \le m \le 10^5$).

Каждая из следующих $m$ строк содержит три целых числа $u$, $v$ и $c$ ($1 \le u, v \le n$, $0 \le c \le 10^5$), задающих ребро между $u$ и $v$ веса $c$. Гарантируется, что граф связен.

## Формат вывода

Выведите вес минимального остовного дерева данного графа.

## Решение

Алгоритм Прима с очередью с приоритетом. Для каждой вершины вне дерева хранится минимальный вес ребра, соединяющего её с деревом; на каждом шаге берётся вершина с наименьшим таким весом и добавляется в дерево вместе с этим ребром.

Очередь - `std::set` пар «вес, вершина». Устаревшие записи не удаляются, а отсеиваются при извлечении по флагу посещения, поэтому обновление ключа сводится к вставке новой пары.

Итого $O(E \log V)$.
