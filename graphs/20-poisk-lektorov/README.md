# N. Поиск лекторов

`1 с` · `512 МБ` · 2 балла · [решение](solution.cpp)

Нужно организовать проведение курса лекций. Есть $n$ лекторов, каждый из которых знает свою уникальную тему, неизвестную остальным.

Перед запуском курса можно организовать встречи некоторых пар лекторов. Если два лектора встречаются, они обмениваются всеми известными им темами, так что оба смогут читать по ним лекции. Организация встречи между $i$-м и $j$-м лектором стоит $p_{ij}$ рублей.

После всех встреч можно пригласить некоторое количество лекторов для чтения лекций так, чтобы все $n$ тем были прочитаны. Приглашение $i$-го лектора стоит $s_i$ рублей.

Разработайте план подготовки курса с минимальными затратами.

## Формат ввода

Первая строка содержит одно целое число $n$ ($2 \le n \le 1000$).

Следующие $n$ строк описывают матрицу стоимостей встреч: в $i$-й строке $n$ чисел, $j$-е из которых равно $p_{ij}$ ($0 \le p_{ij} \le 10^6$, $p_{ii} = 0$).

Последняя строка содержит $n$ целых чисел $s_1, s_2, \ldots, s_n$ ($0 \le s_i \le 10^6$).

## Формат вывода

Выведите минимальную стоимость организации курса.

## Решение

Встречи связывают лекторов в группы: внутри группы все знают все её темы, поэтому от группы достаточно пригласить одного, самого дешёвого лектора. Значит, решение - это лес встреч плюс по одному приглашению на компоненту, и суммарная стоимость минимальна ровно тогда, когда минимален вес остова.

Приглашения удобно свести к тем же рёбрам: добавляется фиктивная вершина $0$ - «курс», и ребро из неё в лектора $i$ веса $s_i$. Тогда задача превращается в минимальное остовное дерево на $n + 1$ вершине: каждая компонента встреч обязана быть соединена с вершиной-курсом ровно одним приглашением.

Дальше - Краскал: все рёбра сортируются по весу и добавляются, если соединяют разные компоненты (система непересекающихся множеств с объединением по размеру). Матрица полная, поэтому рёбер $O(n^2)$.

Итого $O(n^2 \log n)$.
