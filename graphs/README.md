# Графы

Обходы и их приложения (циклы, топсорт, компоненты связности, мосты и точки сочленения), кратчайшие пути, остовные деревья и СНМ.

| # | Задача | Идея решения | Сложность |
|---|--------|--------------|-----------|
| 01 | [Цикл](01-cycle-detection/) | Обход в глубину с тремя цветами, вывод цикла по стеку рекурсии | $O(V + E \log E)$ |
| 02 | [Компоненты связности](02-connected-components/) | Обход в глубину с нумерацией компонент | $O(V + E)$ |
| 03 | [Топологическая сортировка](03-topological-sort/) | Сортировка по убыванию времени выхода | $O(V + E)$ |
| 04 | [Компоненты сильной связности](04-strongly-connected-components/) | Косарайю: два обхода, второй по обратному графу | $O(V + E)$ |
| 05 | [Мосты](05-bridges/) | Функция `low`, кратные рёбра через словарь номеров | $O((V + E)\log E)$ |
| 06 | [Точки сочленения](06-articulation-points/) | Функция `low` с отдельным условием для корня | $O(V + E)$ |
| 07 | [Сжечь мосты](07-szhech-mosty/) | Листья дерева мостов, ответ $\lceil L/2 \rceil$ | $O((V + E)\log E)$ |
| 08 | [Система уравнений](08-system-of-equations/) | Выражение всех вершин через одну, два кандидата на неё | $O(V + E)$ |
| 09 | [Чёт-нечет](09-chet-nechet/) | Значения рёбер остовного леса снизу вверх по чётности | $O(V + E)$ |
| 10 | [Алгоритм Дейкстры](10-dijkstra/) | Дейкстра на `std::set` с ленивым удалением | $O(E \log V)$ |
| 11 | [Распространение вируса](11-rasprostranenie-virusa/) | Одна Дейкстра из финиша, сравнение с ближайшим вирусом | $O(E \log V)$ |
| 12 | [Поиск по двум параметрам](12-poisk-po-dvum-parametram/) | Дейкстра по состояниям «вершина, время» с отсечением по остатку | $O(ns\log(ns) + ms)$ |
| 13 | [Алгоритм Форда-Беллмана](13-bellman-ford/) | $n-1$ проход релаксаций по списку рёбер | $O(nm)$ |
| 14 | [Отрицательный цикл](14-negative-cycle/) | Лишний проход Форда-Беллмана + спуск по предкам | $O(n^3)$ |
| 15 | [Вы не учёный, Мартин Алексеевич](15-vy-ne-uchenyj/) | Флойд на инвертированных весах, метка бесконечных циклов | $O(n^3 + kn)$ |
| 16 | [Транзитивное замыкание](16-transitive-closure/) | Уоршелл | $O(n^3)$ |
| 17 | [Лифты и телепорты](17-lifty-i-teleporty/) | Сжатие этажей + телепорт как вершина, затем Дейкстра | $O(T \log T)$ |
| 18 | [Удаление рёбер](18-udalenie-reber/) | Обработка запросов с конца: разрез становится объединением | $O(q \log n)$ |
| 19 | [MST](19-mst/) | Прим на очереди с приоритетом | $O(E \log V)$ |
| 20 | [Поиск лекторов](20-poisk-lektorov/) | Приглашение как ребро от фиктивной вершины + Краскал | $O(n^2 \log n)$ |
