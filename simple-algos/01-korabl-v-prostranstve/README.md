# L. Корабль в пространстве

`1 с` · `256 МБ` · 4 балла · [решение](solution.cpp)

В пространстве расположены точки в виде прямоугольного параллелепипеда размером $n \times m \times k$: для каждого $x \in [0, n)$, $y \in [0, m)$, $z \in [0, k)$ есть точка $(x, y, z)$ со значением $a_{xyz}$. Все значения $a$ различны.

Космический корабль начинает облетать эти точки. Если он расположен в точке $(x, y, z)$, то на следующем шаге он выбирает новую точку $(x', y', z')$, такую что $x' \in [x, x + a)$, $y' \in [y, y + b)$, $z' \in [z, z + c)$, а среди таких значение $a_{x'y'z'}$ максимально. В частности, корабль может остаться в точке $(x, y, z)$, если в ней достигается максимум. Далее он продолжает путь по тому же правилу.

Для нескольких стартовых позиций определите, где корабль завершит своё путешествие.

## Формат ввода

Первая строка - три целых числа $n, m, k$ ($1 \le n \cdot m \cdot k \le 10^5$).

Вторая строка - три целых числа $a, b, c$ ($1 \le a \le n$, $1 \le b \le m$, $1 \le c \le k$).

Далее $n$ блоков по $m$ строк, в каждой $k$ целых чисел - трёхмерный массив $a$: $z$-е число $y$-й строки $x$-го блока (в 0-индексации) задаёт $a_{xyz}$ ($0 \le a_{xyz} \le 10^9$, все различны).

Следующая строка - число запросов $q$ ($1 \le q \le 10^5$).

Каждая из следующих $q$ строк содержит три числа $x, y, z$ ($0 \le x < n$, $0 \le y < m$, $0 \le z < k$) - стартовые координаты корабля.

## Формат вывода

Для каждого запроса выведите три числа - координаты точки, в которой остановится корабль.

## Решение

Один шаг корабля - это максимум на трёхмерном окне $a \times b \times c$. Считается тремя проходами очереди с максимумом (дек с невозрастающими значениями): сначала окно длины $c$ вдоль оси $z$, затем результат сворачивается окном $b$ вдоль $y$, затем окном $a$ вдоль $x$. Вместе с самим максимумом дек хранит и координаты ячейки, поэтому после трёх проходов для каждой точки известно, куда именно корабль шагнёт.

Переходы образуют функциональный граф, в котором каждая точка ведёт «вверх по значению», поэтому цикл невозможен, а конечная позиция - неподвижная точка. Ответы восстанавливаются одним обратным проходом по сетке со сжатием путей: если максимум окна достигается в самой ячейке, она и есть ответ, иначе ответ копируется у ячейки-максимума, для которой он уже посчитан.

Итого $O(nmk)$ на предподсчёт и $O(1)$ на запрос.
