# M. Игра на цикле

`1 с` · `256 МБ` · 4 балла · [решение](solution.cpp)

По кругу расставлены положительные числа $a_1, a_2, \ldots, a_n$. Два игрока ходят по очереди; на каждом ходу игрок выбирает одно из ещё не выбранных чисел и добавляет его к своему счёту.

На первом ходу первый игрок и на втором ходу второй игрок могут взять любые числа. На последующих ходах игрок может брать только число, соседнее по кругу с одним из уже взятых им чисел.

Каждый игрок максимизирует свой итоговый счёт. Выведите результат игры при оптимальной игре обоих.

## Формат ввода

Первая строка - целое число $n$ ($3 \le n \le 10^6$).

Вторая строка - $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($1 \le a_i \le 10^9$).

## Формат вывода

Два целых числа: счёт первого игрока и счёт второго игрока.

## Решение

Из правил следует, что каждый игрок в итоге забирает непрерывную дугу круга: первый - из $\lceil n/2 \rceil$ чисел, второй - из оставшихся $\lfloor n/2 \rfloor$. Первый ходит первым и выбирает разрез, второй в ответ забирает лучшую доступную ему дугу, поэтому его счёт равен минимуму по выбору первого от максимума по ответу второго.

Суммы всех дуг длины $\lfloor n/2 \rfloor$ считаются за один круговой проход скользящим окном. Максимум ответа второго игрока на каждом варианте разреза - это максимум на окне из $\lceil n/2 \rceil$ подряд идущих таких сумм, он берётся очередью с максимумом. Минимум по всем разрезам даёт счёт второго, счёт первого - дополнение до общей суммы.

Итого $O(n)$ времени и памяти.
