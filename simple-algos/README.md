# Простые задачи

Задачи, не требующие отдельной структуры данных: очередь с максимумом, два указателя, скользящее окно.

| # | Задача | Идея решения | Сложность |
|---|--------|--------------|-----------|
| 01 | [Корабль в пространстве](01-korabl-v-prostranstve/) | Максимум на 3D-окне тремя проходами дека + сжатие путей | $O(nmk + q)$ |
| 02 | [Игра на цикле](02-igra-na-cikle/) | Круговые суммы дуг + очередь с максимумом | $O(n)$ |
