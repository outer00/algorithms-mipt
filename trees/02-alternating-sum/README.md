# C. Знакочередование

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

Дан массив $a_1, a_2, \ldots, a_n$. Обработайте запросы двух видов:

- `0 i x` - присвоить элементу $a_i$ значение $x$;
- `1 l r` - найти знакочередующуюся сумму на отрезке от $l$ до $r$, то есть вывести $a_l - a_{l+1} + a_{l+2} - \ldots + (-1)^{r-l} a_r$.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 10^5$).

Вторая строка содержит $n$ целых чисел - изначальные значения элементов массива $a_1, a_2, \ldots, a_n$ ($0 \le a_i \le 10^4$).

Третья строка содержит одно целое число $q$ ($1 \le q \le 10^5$) - число запросов.

Следующие $q$ строк содержат описание запросов:

- изменение элемента задаётся как `0 i x` ($1 \le i \le n$, $0 \le x \le 10^4$);
- запрос знакочередующейся суммы задаётся как `1 l r` ($1 \le l \le r \le n$).

## Формат вывода

Выведите ответы на все запросы нахождения суммы.

## Решение

Знакочередующаяся сумма сводится к обычной, если заранее домножить элементы на $(-1)^i$: тогда сумма на отрезке $[l, r]$ по изменённому массиву равна искомой с точностью до общего знака. Знак определяется чётностью левой границы - при нечётном $l$ (в 0-индексации) ответ достаточно инвертировать.

Дальше это обычное дерево отрезков на сумму с точечным обновлением, построенное на фиксированных $131072$ листьях в массиве. Обновление меняет лист и поднимает дельту до корня, запрос спускается сверху и отсекает узлы, целиком лежащие внутри или целиком вне отрезка. Присваивание тоже учитывает знак позиции, поэтому инвариант «в дереве лежат элементы со знаками» сохраняется.

Итого $O(\log n)$ на запрос.
