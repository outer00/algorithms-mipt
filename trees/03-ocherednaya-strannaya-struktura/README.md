# G. Очередная странная структура

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Изначально есть пустое мультимножество $S$ (в нём могут быть равные числа). Обработайте запросы двух видов:

- `+ x` - добавить $x$ в $S$;
- `? x` - вывести сумму всех чисел $S$, не превосходящих $x$.

## Формат ввода

Первая строка содержит одно целое число $q$ ($1 \le q \le 10^5$) - число запросов.

Следующие $q$ строк содержат описания запросов в описанном выше формате. Числа $x$ во всех запросах - целые из диапазона $[0, 10^9)$.

## Формат вывода

Выведите ответы на все запросы.

## Решение

Значения доходят до $10^9$, а запросов всего $10^5$, поэтому решение офлайновое: сначала читаются все запросы, их значения сортируются и сжимаются до диапазона размера не больше $q$, и уже на нём строится дерево отрезков на сумму.

Дерево неявное: узлы создаются только при первом обращении, так что памяти уходит $O(q \log q)$, а не $O(q)$ на каждый возможный отрезок. Запрос «сумма не превосходящих $x$» - это префиксная сумма до сжатой позиции $x$: спуск отсекает узлы, целиком лежащие левее границы, целиком берёт сумму такого узла и уходит в правого сына, а отсутствующие поддеревья считаются нулевыми.

Итого $O(q \log q)$.
