# J. Просто Фенвик

`1 с` · `256 МБ` · 2 балла · [решение](solution.cpp)

Дана квадратная матрица $n \times n$, все элементы которой изначально равны нулю. Обработайте запросы двух видов:

- `ADD x y` - увеличить значение в клетке $(x, y)$ на $1$;
- `GET x1 y1 x2 y2` - вывести сумму значений элементов матрицы в прямоугольнике с углами $(x_1, y_1)$ и $(x_2, y_2)$ включительно. Эти углы противоположны, но не обязательно являются левым нижним и правым верхним.

## Формат ввода

Первая строка содержит два целых числа $n$ и $q$ ($1 \le n \le 10^3$, $1 \le q \le 3 \cdot 10^5$) - размер доски и число запросов.

Каждая из следующих $q$ строк содержит описание запроса в описанном выше формате.

## Формат вывода

Выведите ответы на все запросы.

## Решение

Двумерное дерево Фенвика. Индексация нулевая, поэтому переходы записываются битовыми операциями: `i | (i + 1)` - следующий узел, отвечающий за позицию при обновлении, `(i & (i + 1)) - 1` - предыдущий блок при подсчёте префикса. Оба цикла вложены друг в друга: обновление и запрос идут по $O(\log^2 n)$ ячейкам.

Сумма по прямоугольнику собирается по формуле включения-исключения из четырёх префиксных сумм. Углы приходят в произвольном порядке, поэтому границы сначала приводятся к виду «минимум - максимум» по каждой координате; выход за левый край даёт нулевой префикс.

Итого $O(\log^2 n)$ на запрос при $O(n^2)$ памяти.
