# A. Декартово дерево

`1 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

В этой задаче нужно построить декартово дерево по данному набору точек за линейное время.

Даны $n$ пар целых чисел $(x_i, y_i)$. Гарантируется, что $x_1 < x_2 < \ldots < x_n$, а все значения $y_i$ попарно различны. Определите, возможно ли построить декартово дерево на этих точках. Если возможно, выведите его структуру.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 50\,000$).

В $i$-й из следующих $n$ строк содержится два целых числа $x_i$ и $y_i$ ($|x_i|, |y_i| \le 30\,000$).

## Формат вывода

Если по данным точкам нельзя построить декартово дерево, выведите «NO».

Иначе в первой строке выведите «YES», а в следующих $n$ строках - описание дерева: номер предка вершины $i$, номер её левого сына и номер правого сына. Если какой-либо вершины не существует, выведите вместо неё $0$.

Если подходящих деревьев несколько, выведите любое.

## Решение

Ключи уже отсортированы, поэтому декартово дерево строится за один проход по правому хребту - цепочке правых сыновей от корня. Ответ «NO» невозможен: при различных $y_i$ дерево существует всегда.

Очередная точка сравнивается с вершинами хребта снизу вверх, пока не найдётся вершина с меньшим приоритетом. Дальше три случая: новая вершина становится корнем и забирает старый корень в левое поддерево; подвешивается правым сыном найденной вершины; либо встраивается между найденной вершиной и её правым поддеревом, которое становится левым поддеревом новой вершины.

Каждая вершина попадает на хребет один раз и уходит с него один раз, поэтому суммарное число шагов подъёма линейно. Итого $O(n)$.
