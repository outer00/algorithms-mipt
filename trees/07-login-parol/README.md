# C. Логин-пароль

`2 с` · `256 МБ` · 1 балл · [решение](solution.cpp)

На сайте зарегистрированы $n$ человек. Каждый пользователь характеризуется логином и паролем. Гарантируется, что все логины попарно различны, все пароли попарно различны, а также что паролем пользователя не может выступать имя какого-либо пользователя - то есть все строки попарно различны.

Нужно обработать $q$ запросов, в которых по логину пользователя требуется восстановить его пароль или, наоборот, по паролю восстановить логин.

## Формат ввода

Первая строка содержит одно целое число $n$ ($1 \le n \le 10^5$). Каждая из следующих $n$ строк содержит по два слова: логин пользователя и его пароль.

Следующая строка содержит одно целое число $q$ ($1 \le q \le 10^5$). Каждая из следующих строк содержит одно слово (последовательность из маленьких латинских букв). Если слово является паролем какого-то пользователя, нужно восстановить его логин; если слово является чьим-то логином - вывести пароль этого пользователя.

Гарантируется, что все слова попарно различны, а суммарная длина всех слов не превосходит $10^8$.

## Формат вывода

Выведите ответы на все запросы.

## Решение

Все строки попарно различны, поэтому логин и пароль можно не различать: пара кладётся в словарь дважды, в обе стороны. Тогда любой запрос - это одно обращение по ключу, а разбор «логин это или пароль» не нужен вовсе.

Хранилище - `std::map` (красно-чёрное дерево), поиск и вставка за $O(\log n)$ сравнений строк. Итого $O((n + q)\log n)$ операций со строками.
