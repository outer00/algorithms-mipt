# Количество чисел из диапазона на отрезке

`3 с` · `256 МБ` · [решение](solution.cpp)

В этой задаче нет ограничений на используемые структуры данных.

Дан массив $a_1, a_2, \ldots, a_n$. Обработайте $q$ запросов двух видов:

- `SET i x` - присвоить элементу $a_i$ значение $x$;
- `GET l r x y` - определить, сколько из чисел $a_l, a_{l+1}, \ldots, a_r$ лежат в диапазоне $[x, y]$.

## Формат ввода

Первая строка содержит два целых числа $n$ и $q$ ($1 \le n, q \le 10^5$) - длину массива и число запросов.

Вторая строка содержит $n$ целых чисел $a_1, a_2, \ldots, a_n$ ($1 \le a_i \le n$).

Следующие $q$ строк содержат описание запросов. В запросе `SET` гарантируется $1 \le i \le n$ и $1 \le x \le n$, в запросе `GET` - $1 \le l \le r \le n$ и $1 \le x \le y \le n$.

## Формат вывода

Выведите ответы на все запросы.

## Решение

Дерево отрезков, в узлах которого лежат не числа, а деревья поиска: каждый узел хранит мультимножество всех значений своего отрезка. Тогда запрос «сколько значений из $[x, y]$» на отрезке разбивается на $O(\log n)$ узлов дерева отрезков, и в каждом ответ считается как разность двух порядковых запросов по его дереву - количество значений меньше $y + 1$ минус количество значений меньше $x$.

Мультимножества реализованы splay-деревом с размерами поддеревьев; повторные значения не создают новых узлов, а увеличивают размер существующего. Обновление элемента спускается до листа и по дороге удаляет старое значение и вставляет новое в каждом узле пути - то есть в $O(\log n)$ мультимножествах.

Итого $O(\log^2 n)$ на запрос при $O(n \log n)$ памяти.
