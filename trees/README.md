# Деревья

Деревья отрезков (в том числе неявные и с деревьями поиска в узлах), дерево Фенвика, декартово дерево, splay-дерево.

| # | Задача | Идея решения | Сложность |
|---|--------|--------------|-----------|
| 01 | [Марафон](01-marafon/) | Дерево отрезков по координате, префиксные суммы участников | $O(\log n)$ на запрос |
| 02 | [Знакочередование](02-alternating-sum/) | Домножение на $(-1)^i$ сводит задачу к обычной сумме на отрезке | $O(\log n)$ на запрос |
| 03 | [Очередная странная структура](03-ocherednaya-strannaya-struktura/) | Офлайн-сжатие координат + неявное дерево отрезков | $O(q \log q)$ |
| 04 | [Просто Фенвик](04-fenwick-tree/) | Двумерное дерево Фенвика, сумма прямоугольника по включению-исключению | $O(\log^2 n)$ на запрос |
| 05 | [Декартово дерево](05-cartesian-tree/) | Построение по отсортированным ключам через правый хребет | $O(n)$ |
| 07 | [Логин-пароль](07-login-parol/) | Двусторонний словарь: пара кладётся в обе стороны | $O((n + q)\log n)$ |
| 08 | [Упорядоченное дерево](08-splay-tree/) | Splay-дерево с размерами поддеревьев | $O(\log n)$ амортизированно |
| 09 | [Сумма на отрезке](09-range-sum/) | Splay с суммой поддерева, отрезок как разность префиксов | $O(\log n)$ амортизированно |
| 10 | [Отрезки на прямой](10-otrezki-na-pryamoj/) | Треап по координате начала, в узле сумма квадратов длин | $O((n + q)\log n)$ |
| 11 | [Количество чисел из диапазона на отрезке](11-range-count-queries/) | Дерево отрезков из деревьев поиска | $O(\log^2 n)$ на запрос |
